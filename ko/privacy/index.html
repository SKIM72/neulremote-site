개인정보 처리방침

시행일: 2026-10-25

이 방침은 NeulRemote(Android 앱, 웹 앱, PC 앱, NeulRemote 서버, 이 사이트)가 어떤 정보를 왜 처리하는지 설명합니다.

처리하는 정보와 목적

  • 계정: 이메일 주소, 이름, 비밀번호(서버는 되돌릴 수 없는 해시로만 저장), 프로필 사진(선택), 역할 — 로그인, 내 기기 보기, 계정 보호.
  • 로그인 세션: 접속 IP 주소, 브라우저·앱 정보(User-Agent), 시각 — 로그인 유지와 부정 사용 확인.
  • 등록한 기기: 기기 이름, 제조사·모델, Android·앱 버전, 기기 종류, 원격 대기 상태, 배터리, 권한 등급, 마지막 접속 시각, Google Play 서비스가 있는 폰은 푸시 주소(Firebase Cloud Messaging 토큰) — 내 폰 목록과 연결, 연결할 때 잠든 폰을 깨우기.
  • 원격 연결: 두 기기를 이어 주는 데 필요한 연결 정보. 화면·소리·입력·음성 통화는 기기끼리 암호화되어 오가며 서버에 저장하지 않습니다. 바로 연결이 안 되면 암호화된 채로 중계 서버(TURN)가 전달만 하며 내용을 볼 수 없습니다.
  • 원격 도움 링크: 링크 상태와 임시 기기 정보 — 연결이 끝나면 지웁니다(10분·한 번만).
  • 오류 보고: 오류 내용과 코드 위치, 앱 버전, 기기 요약(Android 버전·제조사·모델 또는 OS·브라우저), 로그인했다면 계정 — 문제 해결. 이메일·토큰·IP 주소는 가린 뒤 저장하고 30일이 지나면 지우며, 앱 설정에서 끌 수 있습니다.
  • 이메일: 가입 인증·비밀번호 재설정 메일 발송.
  • 의견 보내기: 메일 앱으로 직접 보내신 메일과(고르신 경우) 개인정보를 가린 개발자 로그 — 답변과 문제 해결.
  • 서버 기록: 보안과 장애 대응을 위해 요청 주소·시각·IP 주소가 서버 로그에 남을 수 있습니다.

폰에만 저장되는 것

  • 페어링 키, 접속 기록(누가 언제 연결했는지), 설정은 기기에만 저장하며 서버로 보내지 않습니다.

보관 기간

  • 계정 정보는 삭제를 요청하실 때까지 보관합니다. 세션은 로그아웃하거나 만료되면 끝납니다. 오류 보고는 30일이 지나면 지웁니다.
  • 장애 복구를 위해 서버를 매일 별도 디스크에 백업합니다. 지운 정보도 백업에는 한동안 남을 수 있습니다.

제3자 제공과 외부 서비스

  • 광고·분석 도구를 쓰지 않으며 정보를 판매하거나 제3자에게 제공하지 않습니다.
  • 서비스에 쓰는 외부 서비스: Google Gmail(메일 발송), Google Firebase Cloud Messaging(연결할 때 잠든 폰 깨우기 — 폰의 푸시 주소와 ‘깨우기’ 신호만 전달, 화면 내용 없음), DuckDNS(서버 주소), GitHub(이 사이트 호스팅·앱 업데이트 파일 전달). 이 사이트는 GitHub Pages에서 제공되며 방문자의 IP 주소가 GitHub에서 처리됩니다.

이용자의 선택과 권리

  • 앱에서 로그아웃, 기기 등록 해제, 오류 보고 끄기를 할 수 있습니다. 정보의 열람·정정·삭제·처리 정지는 이메일로 요청해 주세요.
  • 만 14세 미만은 보호자 동의 없이 가입하지 마세요.

안전 조치

  • 모든 연결에 HTTPS, 비밀번호 해시 저장, 원격 연결 암호화, 운영자만 접근, 방화벽과 키로만 접속하는 서버 관리.
