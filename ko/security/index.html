NeulRemote 보안

NeulRemote는 다른 기기의 화면을 보고 조작하는 앱이라 보안을 가장 먼저 생각합니다. 무엇이 어디로 가고, 서버가 무엇을 볼 수 있고 볼 수 없는지 정리했습니다.

화면·소리·입력은 기기끼리 암호화

  • 화면, 소리, 터치·키보드 입력, 파일, 음성 통화는 WebRTC(DTLS·SRTP)로 두 기기 사이에서 암호화되어 오갑니다. 암호를 푸는 열쇠는 두 기기만 갖고 있습니다.
  • 인터넷 연결에서 두 기기가 직접 닿지 못하면 NeulRemote 중계 서버(TURN)를 거칩니다. 이때도 암호화된 채 전달만 하므로 서버는 내용을 볼 수 없고 저장하지 않습니다.

서버가 아는 것과 모르는 것

  • 아는 것: 계정(이메일·이름·비밀번호의 한 방향 해시), 등록한 기기와 상태(모델·Android 버전·배터리·마지막 접속), 두 기기를 잇는 데 필요한 정보(어느 기기가 언제 연결을 요청했는지).
  • 모르는 것: 화면에 보이는 내용, 소리, 입력한 글자, 보낸 파일, 통화 내용. 비밀번호 원문도 모릅니다. 자세한 내용은 개인정보 처리방침에 있습니다.

서버 없이 쓰는 방법

  • 같은 Wi‑Fi에서 연결하거나 USB로 연결하면 계정과 서버 없이 기기끼리 바로 잇습니다. 같은 Wi‑Fi에서는 처음 한 번 두 화면의 여섯 자리 숫자가 같은지 확인해 페어링합니다.

"중계 서버 거치지 않기"

  • 앱(설정 → 원격 화면)과 웹 앱(설정 → 원격 화면)에서 중계 서버 거치지 않기를 켜면 인터넷 연결도 중계 없이 기기끼리 직접만 잇습니다.
  • 직접 연결이 막힌 망(일부 LTE·회사·학교 Wi‑Fi)에서는 켜 두면 연결되지 않으니 그때는 끄세요. 조작받는 폰도 최신 앱이어야 완전히 적용됩니다.

조작받는 폰은 늘 주인이 통제

  • 원격 대기는 폰 주인이 직접 켜야 하고, 켜져 있는 동안 알림이 늘 보이며 알림에서 바로 멈출 수 있습니다.
  • 폰을 계정에 등록하려면 그 폰에 뜨는 코드가 필요합니다.
  • 원격 도움 링크는 한 번만, 10분 동안 쓸 수 있고 상대가 허용해야 연결되며 연결이 끝나면 권한도 사라집니다. 폰 주인이 늘 볼 수 있도록 도움 링크 연결에서는 폰 화면 끄기·클립보드 가져오기·루트 기능을 쓸 수 없습니다.
  • 잠금 화면 우회, 시스템 동의 창 자동 클릭, PIN·비밀번호 저장을 하지 않습니다.

계정 보호

  • 처음 쓰는 기기에서 이메일·비밀번호로 로그인하면 계정 이메일로 보낸 6자리 코드를 한 번 더 확인합니다.
  • 비밀번호를 바꾸면 다른 기기의 로그인이 모두 끊깁니다.
  • 구글로 로그인하면 구글 계정의 2단계 인증이 그대로 적용됩니다. 구글 로그인을 연결하거나 해제하면 계정 메일로 알려 드립니다.
  • NeulRemote는 메일이나 전화로 비밀번호·인증 코드를 묻지 않습니다.

서버 운영

  • 모든 통신은 HTTPS, 비밀번호는 한 방향 해시로만 저장, 서버는 방화벽 뒤에서 키로만 관리, 백업은 30일 뒤 자동으로 지웁니다.

보안 문제 알리기

  • 문제를 발견하면 support@neulremote.com로 알려 주세요.
