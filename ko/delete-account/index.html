NeulRemote 계정 삭제

NeulRemote 계정과 NeulRemote 서버에 있는 내 데이터를 지우는 방법입니다. 지우면 되돌릴 수 없습니다.

앱에서

  • NeulRemote 앱 → 오른쪽 위 프로필 → 계정 삭제 → 비밀번호를 넣고 [계정 삭제].

웹에서

  • 웹 앱에 로그인 → 계정 옆 계정 삭제(휴대폰 화면은 계정 → 계정 관리 → 계정 삭제) → 비밀번호를 넣고 [계정 삭제].

앱을 쓸 수 없을 때

  • 가입한 이메일로 support@neulremote.com에 계정 삭제를 요청하세요. 본인인지 확인한 뒤 지우고 답장드립니다.

지우는 것

  • 바로 지웁니다: 계정(이메일·이름·비밀번호 해시·역할), 로그인 세션, 등록한 폰과 그 상태, 원격 도움 링크, 연결 기록, 프로필 사진, 알림(푸시) 주소, 로그인 확인 기기. 등록했던 폰은 원격 대기가 끊기고 등록이 풀립니다.

남는 것

  • 오류 보고는 계정과의 연결을 끊은 채(이메일·토큰·IP는 이미 가려 저장) 30일이 지나면 지워집니다.
  • 계정을 지웠다는 기록(내부 번호와 시각, 이메일 없음)을 보안을 위해 남깁니다.
  • 장애 복구용 서버 백업에는 지운 정보가 최대 30일 남을 수 있습니다. 30일이 지난 백업은 저절로 지워집니다.
  • 폰에만 저장되는 페어링 키·접속 기록·설정은 앱을 지우면 함께 지워집니다.
