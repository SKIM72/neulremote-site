iPhone·iPad로 조작하기

아이폰·아이패드는 앱 설치 없이 Safari 웹 앱을 씁니다. 조작받을 Android 폰을 계정에 등록해 두세요(준비 4단계). 아이폰·아이패드는 조작하는 쪽만 됩니다.

먼저 조작받을 Android 폰을 준비하세요 → 폰 준비하기

1. 웹 앱 열고 홈 화면에 추가

  1. Safari로 https://app.neulremote.com을 엽니다. 아래(아이패드는 위)의 공유 → 홈 화면에 추가를 누르면 주소창 없이 앱처럼 열립니다.

2. 로그인

  1. Android 앱에서 쓰는 계정으로 로그인합니다. 계정이 없으면 여기서 만들 수 있습니다.

3. 조작받을 폰 등록 (처음 한 번)

  1. 기기 등록을 누르고, 조작받을 폰의 등록 코드 받기에서 본 6자리 코드를 넣어 등록합니다. 이미 등록돼 있으면 건너뜁니다.

4. 연결

  1. 내 기기에서 “접속 가능”인 폰의 연결 (인터넷)을 누릅니다. 폰이 기본 등급(T0)이면 폰에서 화면 공유를 허용해야 합니다.

5. 조작

  1. 화면을 누르고 밀어서 조작합니다. 아래 버튼 줄: 뒤로·홈·최근 앱·음량·소리·전원·키보드·확대·연결 해제. 글자는 [키보드] 버튼을 눌러 칩니다. 가로로 돌리면 버튼 줄이 오른쪽으로 갑니다.

알아 둘 것

  1. 앱을 내리거나 화면이 꺼지면 iOS가 연결을 끊습니다. 돌아오면 자동으로 다시 연결합니다.
  2. 소리가 안 나면 화면을 한 번 누르세요(iOS는 누른 뒤에만 소리를 냅니다). 무음 스위치를 켜 둬도 원격 소리는 들립니다.
  3. 아이패드는 매직 키보드·트랙패드를 그대로 쓸 수 있습니다(오른쪽 클릭 = 뒤로).
