Windows PCから操作する

Windows 10・11（64ビット）にNeulRemoteアプリを入れると、同じWi‑Fi・インターネット（アカウント）・USBでスマホを操作できます。インストールしたくない場合は、ChromeやEdgeでWebアプリも使えます — PCのブラウザから。

まず 操作されるAndroid端末 を準備してください → 端末の準備

1. インストール

  1. インストーラーをダウンロードして実行します。管理者権限なしで自分のWindowsアカウントにインストールされ、終わるとアプリが開きます。
  2. ARMノートPC（Snapdragonなど）はARM用インストーラーをダウンロードしてください。
  3. まだコード署名をしていないため、警告が出ることがあります。ブラウザが「一般的にダウンロードされていない」と表示したら 保存 を、Windowsが WindowsによってPCが保護されました と表示したら 詳細情報 → 実行 を押してください。
  4. 新しいバージョンが出ると、アプリが自動でダウンロードし、今すぐ再起動するか聞きます。リモート接続中なら 後で を — アプリを閉じるときに更新されます。今の状態は 設定 → 情報 → 更新 で確認でき、アップデートを確認 ですぐに探すこともできます。

2. 接続

  1. スマホの準備は 端末の準備 と同じです。アプリでログインするとアカウントに登録したスマホが、同じWi‑Fiではリモート待機中のスマホが表示されます。選んで接続してください。
  2. Googleアカウントは Google のボタンを押すと、既定のブラウザにGoogleアカウントの選択画面が出ます。アカウントを選ぶとアプリに戻ります。
  3. スマホごとに別のウィンドウが開き（無料は1つ、Proは複数）、ウィンドウはスマホの形に合わせます。ファイルをスマホのウィンドウにドラッグ＆ドロップするとスマホへ送ります。

USBで接続するとき

  1. スマホでUSBデバッグをオンにしてUSBでつなぐと、アプリがスマホを見つけます。PCにadb（Android SDK Platform-Tools）があればそれを使い、なければアプリが直接つなぎます。
  2. スマホに NeulRemote アプリがあれば、キーボードは NeulRemote キーボード — PCの入力システムで変換した文字をそのまま入力します。アプリがなければ物理キーボードのエミュレーションで入力し、ツールバーのキーボードメニューで切り替えられます。
  3. 端末によってはUSBドライバーが必要です（例: GalaxyはSamsung USB Driver、PixelなどはGoogle USB Driver）。
  4. Samsung Galaxy S9（Android 10）で確認しました（PCにadbがある場合・ない場合とも）。ほかの端末でうまくいかないときは同じWi‑Fiかインターネット（アカウント）接続を使い、お知らせください。

ワイヤレスデバッグで（ケーブルなし）

  1. Android 11以上のスマホは、ケーブルなしでUSBと同じように接続できます。PCにadbがなくても使えます。
  2. スマホとPCを同じWi‑Fiにつなぎ、スマホの 開発者向けオプション → ワイヤレスデバッグ をオンにします。アプリの USB · ワイヤレスデバッグ → ワイヤレス接続 で、スマホの QR コードでデバイスをペア設定 からQRを読み取るか、ペアリングコード タブにスマホに出た6桁のコードを入力します。
  3. 一度ペア設定すると、次からは一覧で 接続 を押すだけです。公共のWi‑Fiではワイヤレスデバッグをオンにしたままにしないでください。

エクスプローラーでスマホのストレージ

  1. USBかワイヤレスデバッグで接続したスマホは、Windowsのエクスプローラー左側の NeulRemote の下にスマホごとのフォルダーとして表示されます。フォルダーを開くとスマホの内部ストレージの一覧を受け取り、写真・動画は開いたりPCにコピーしたりしたときにダウンロードします（OneDriveのように）。
  2. ダウンロードしたファイルはスマホを外しても開けます。右クリックの 空き領域を増やす でPCの容量を空け、このデバイス上で常に保持する で先にダウンロードしておけます。
  3. スマホのフォルダーにファイルやフォルダーをコピー・ドラッグ＆ドロップすると、スマホにアップロードされます。新しいフォルダー・名前の変更・同じスマホ内の移動もそのまま反映され、PCで編集したファイルもアップロードされます（その間にスマホ側も変わっていたら「名前 (PC コピー)」として別に保存）。
  4. スマホのファイルの削除はできません — スマホにはごみ箱がなく元に戻せないためです。エクスプローラーからスマホのフォルダーを外すには 設定 → エクスプローラーのスマホフォルダー → エクスプローラーから外す（このPCにダウンロードしたコピーだけを削除）。

通知領域・PCの起動時に開始

  1. アプリの起動中は通知領域（トレイ）にアイコンがあります。押すとデバイス一覧が開き、メニューから終了できます。
  2. 設定 → PC アプリ → PCの起動時に NeulRemote を開始 をオンにすると、PCの起動時にウィンドウを出さずに通知領域で待機し、アイコンを押すと開きます。

アンインストール

  1. Windowsの 設定 → アプリ → インストールされているアプリ からNeulRemoteを削除します。
