NeulRemoteアカウントの削除

NeulRemoteアカウントと、NeulRemoteサーバー上のあなたのデータを削除する方法です。削除は元に戻せません。

アプリで

  • NeulRemoteアプリ → 右上のプロフィール → アカウントを削除 → パスワードを入力して[アカウントを削除]。

Webで

  • Webアプリにログイン → アカウントの横のアカウント削除（スマホ画面ではアカウント → アカウント管理 → アカウント削除）→ パスワードを入力して[アカウント削除]。

アプリを使えないとき

  • 登録したメールアドレスからsupport@neulremote.comへアカウント削除をご依頼ください。ご本人確認のうえ削除し、ご返信します。

削除されるもの

  • すぐに削除します：アカウント（メールアドレス・名前・パスワードのハッシュ・役割）、ログインセッション、登録したスマホとその状態、リモートヘルプのリンク、接続履歴、プロフィール写真、通知（プッシュ）先、ログイン確認済みの端末。登録していたスマホはリモート待機が切れ、登録が解除されます。

残るもの

  • エラーレポートはアカウントとの関連付けを外した状態で（メールアドレス・トークン・IPはすでにマスク済み）30日後に削除されます。
  • アカウントを削除した記録（内部番号と日時、メールアドレスなし）をセキュリティのため保管します。
  • 障害復旧用のサーバーバックアップには、削除した情報が最大30日間残ることがあります。30日を過ぎたバックアップは自動的に削除されます。
  • スマホにだけ保存されるペアリング鍵・接続履歴・設定は、アプリを削除すると一緒に消えます。
